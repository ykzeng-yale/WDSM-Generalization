# Weighted matching

Development extension of the `wdsmatch` R package. This repository contains package source, reproducible synthetic simulations and validation code. The manuscript and research source documents are maintained separately and are not included here.

The current Weighted Matching framework uses supplied, known probability weights `W = w_Z(X)`, including `w(X)`. These supplied weights may vary between individuals. Matching scores, coordinate scales and outcome corrections may be estimated. Estimation error in the weights is outside this framework. Historical optional weight-fitting APIs and study artifacts retained from the earlier development snapshot are identified below; they are not current WM theory or validation claims.

The matching engine matches each query to exactly `M` opposite-arm donors using Euclidean coordinates. Fixed-map functions accept supplied coordinates; `wm_wdsm_fit()` constructs fitted, arm-specific double scores; `wm_model_fit()` accepts finite lists of propensity and arm-specific prognostic models. Weights enter the target population, the query contributions and, for the original rule, each donor-set normalization. The original `wdsmatchATE()` and `wdsmatchATT()` interfaces remain available.

For iid observations with law Q and fixed weights W=w_Z(X), the target law is dP/dQ=W/E_Q(W). PATE averages the causal effect under P; PATT averages it among treated individuals under P. Weights may depend on treatment and covariates, with covariate-only weights as a special case. Recovering an external population using sampling or response weights requires the corresponding identification assumptions. Balancing weights also define a target through this law; their name alone does not establish identification or the required residual centering.

## Installation

From this source checkout, run `R CMD INSTALL .` in a terminal. In R, load the package with `library(wdsmatch)`. The package name remains `wdsmatch`; installing this development version updates an existing installation of that name.

## Fixed matching maps

```r
library(wdsmatch)
set.seed(928)
n <- 400
X <- matrix(runif(2 * n), n, 2)
Z <- rbinom(n, 1, plogis(-0.2 + 0.5 * X[, 1]))
W <- ifelse(Z == 1, 1 + X[, 1], 1 + 0.5 * X[, 2])
Y <- 1 + X[, 1] + X[, 2]^2 + Z + runif(n, -0.5, 0.5)

fit <- wm_fit(Y, Z, W, scores0 = X, M = 3,
              estimand = "PATE", regression = "polynomial", degree = 2)
fit$estimate
fit$se
wm_bootstrap(fit, B = 999, seed = 17)$conf.int
```

`wm_match()` accepts supplied mean predictions; `wm_fit()` fits complete weighted polynomials or tensor B-splines. Neither changes the supplied coordinate scaling. Bias correction imputes a query's predicted mean plus matched donor residuals. PATT needs only the control mean. Graphs, donor fractions, incoming loads, contribution rows and numerator identities are returned for inspection.

The default `self_normalized` row variance requires the stated strong residual centering conditional on weights and the matching graph's score field. Weighted score centering alone is insufficient. The `stabilized` rule uses a conditional-weight mean and has a different estimator and inference formula. Its existing row/edge PATE variance requires a common score and bounded outcomes. For distinct fixed arm maps, calculate the corrected point with `variance = FALSE`, then use `wm_reciprocal_inference()` under its separate bounded fixed-map assumptions. `wm_potential()` and `wm_split_pate()` provide the separately justified one-direction and independent-block constructions.

## Fitted double scores

`wm_wdsm_fit()` uses positive probability weights and jointly fits a logistic propensity model, separate ordinary arm prognostic regressions, pooled score centering/scaling, and weighted quadratic bias correction. Its default `ps_weighting = "probability"` weights the PS fit; `ps_weighting = "unit"` reproduces the original prospective unweighted PS fit. This choice is propagated through the estimating equations, Jacobian and influence calculation, while target normalization, donor fractions and correction still use the supplied probability weights. It follows the reviewed source WDSM pipeline and retains its self-normalized donor fractions and arm-specific two-coordinate maps. Regression designs may have different numbers of columns; the matching dimension is still two. Include intended intercepts in the supplied design matrices.

```r
ps_design <- cbind(intercept = 1, X)
pg_design <- cbind(intercept = 1, x1 = X[, 1], x2_squared = X[, 2]^2)

# Point estimation is the default; M is a chosen positive integer.
wdsm_point <- wm_wdsm_fit(Y, Z, W, ps_design, pg_design,
                         pg1_design = pg_design, M = 3, estimand = "PATE")
wdsm_point$estimate

# PATT fits only the control prognostic and correction models.
wdsm_att <- wm_wdsm_fit(Y, Z, W, ps_design, pg_design,
                       M = 1, estimand = "PATT")
```

The default `inference = "none"` withholds standard errors and intervals. Set `inference = "full_x"` to request the conditional fitted-score variance, including all PS/PG/standardization/correction influences and their covariance with matching contributions. Correct full-X correction means, independent observations, identification, the complete regular root and the applicable baseline/current score geometry must be justified. The finite-moment d>=2 full-X alternative in `?wm_fitted_inference` permits unbounded outcomes and nuisance influences, retaining bounded smooth correct predictions, finite `2+delta` moments of the full influence's conditional design mean, and uniformly bounded conditional `2+delta` residual and centered-influence moments. The separate complete Gaussian route permits unbounded supplied weights and correct full-X predictions under exact design/noise-projection graph determination, integrated uniform current-graph moments, prediction derivative/Hessian envelopes, the actual slope limit and complete influence conditions. Its source double-score chart/minor and propensity-interaction restrictions remain application premises; a misspecified PS minor needs separate verification. Every PS/PG/centering/scaling/correction equation and covariance block remains. Selecting an option or obtaining a converged fit does not verify the population or numerical-root/graph conditions. Other own-field/estimated-transport routes retain their bounded assumptions. The examples illustrate the interface. Weights and optional offsets are known; estimated-weight uncertainty, unrestricted learned maps and cluster/stratum sampling dependence remain outside this wrapper's scope.

No bootstrap is run by this fitting wrapper. The common `wm_bootstrap()` interface supports the original count-refit calculation with `method = "fixed_reuse"`, supplied counts, and an explicit callback that returns complete refitted mean predictions. Passing the nested matching fit without that callback keeps its predictions fixed and does not account for the complete fitted-score pipeline. Contribution and count-refit procedures can have different finite-sample variances. Legacy `wdsmatchATE()` and `wdsmatchATT()` interfaces remain unchanged.

## Multiple fitted score models

`wm_model_fit()` accepts `ps_models`, `pg0_models` and `pg1_models` lists of explicit design/offset descriptors. Each PS model is fitted once and shared across arms; PS fitting weights can be declared separately as `"probability"` or `"unit"`. Arm-specific PG fits remain ordinary least squares. With J PS and K_z arm PG models, the matching dimension is J+K_z, while the complete nuisance dimension also includes all regression coefficients, pooled centers/variances and full quadratic correction coefficients. Distinct arm dimensions and PS-only/PG-only point paths are supported. Intended intercepts belong in the supplied designs.

The original supplied weights, fixed M donor fractions and PATE/PATT normalization are retained. One PS and one PG per used arm dispatches to the original `wm_wdsm_fit()` arithmetic. All generated-coordinate Jacobian and covariance blocks remain; dependent outputs are not silently deleted. `max_stack_elements` rejects an oversized complete stack before fitting and is an array-element guard, not a bound on total memory.

Point-only inference is the default. `inference = "full_x"` is conditional on correct full-X correction means and the applicable actual-root, geometry and row/slope conditions; a correct PS alone does not establish them. It supports all-vector or all-scalar maps under their respective premises, with mixed scalar/vector inference unavailable. The wrapper does not calculate generic nonzero graph transport or run a bootstrap. PS-only output still uses quadratic correction, so it is not automatically the raw PSM statistic. See `?wm_model_fit` for descriptors, failure records and the inference scope.

## Fitted scalar propensity scores

`wm_scalar_logistic_match()` fits every coefficient in a supplied intercept-containing logistic design and applies raw matching to the fitted probability, with fixed `M` and the original donor fractions. Its separate variance calculation allows varying means and outcome variation in both arms under the documented bounded model, including dependent covariates on a smooth common conditional-score interval. Known functions `w0`, `w1` and their derivatives are required for this inference branch; an observed weight vector alone is insufficient. The inference theorem uses at least three design columns. Lower-dimensional raw points can still be returned with inference unavailable.

Own-arm triangular-kernel regressions estimate variance moments only; they do not correct the point or change its graph. Complete heterogeneity, finite-`M` drift, matching/nuisance covariance and sandwich terms are retained. Both estimands use total observed `n` in `V/n`. A calculated interval is conditional on the population and numerical-root requirements: the interface reports `numerical_root_bridge = "not_certified"` and does not establish the original refit bootstrap. Runtime inference failures preserve an already computed point; malformed arguments fail before fitting. See `?wm_scalar_logistic_match` for the full contract and failure fields.

`wm_scalar_replication(fit)` separately computes centered current-graph contributions and the full fitted-score correction for the same qualified scalar model. It preserves the raw point, retains matching/nuisance covariance, and uses total observed `n` for PATE and PATT. Optional supplied count or multiplier matrices produce linear contribution replicates without refitting or rematching; their distribution remains the caller's responsibility. Its row variance can differ from the explicit moment variance in a finite sample. Population assumptions and the numerical-root bridge remain required; this does not validate the original refit bootstrap. See `?wm_scalar_replication` and `validation/check_scalar_replication.R`, which uses a saved synthetic fixture without new fits or random draws.

`wm_scalar_root_certificate(fit, design)` separately checks the stored numerical result, using optional `gmp` and `Rmpfr` dependencies. It can certify existence and uniqueness of the exact weighted logistic root, equality of the recorded donor sets, and an explicit point-arithmetic error bound. These are separate finite-data conclusions. Inconclusive checks preserve the fit; a pass does not establish a population assumption, asymptotic success rate, variance-arithmetic accuracy or bootstrap validity. The supplied design and stored data define the exact problem being checked. See `?wm_scalar_root_certificate` and `validation/check_scalar_root_certificate.R`.

For known weights varying within a propensity score, use the existing `wm_fitted_inference(fit, covariance_scope = "scalar_psm")` on a raw `wm_scalar_logistic_match(..., inference = FALSE)` object. This branch permits general fixed regression dimension p>=2 and positive W(Z,X), retaining the original finite-M donor denominators and raw PATE/PATT point. It derives the weighted-logistic influence and finite-M drift from the bound design, conditional empirical Laplace transforms and C2 scalar smoothers. It returns complete centered contribution rows, the full variance identity V0+2b'C+b'Sigma b, and V/n using total observed n. PATT needs only the control mean.

`scalar_control` records smoothing constants and computational caps. M=1 and constant donor weights use exact expressions; other laws use shared chunked Gauss-Legendre integration with interval and tail errors propagated directly to b. Defaults cap the two Laplace matrix products at 2 billion terms. Empty trims or exceeded integration budgets report unavailable inference and preserve the point. The integration bound excludes floating roundoff and statistical smoothing error. Population smoothness, target/own-weight centering, regular root and numerical-root bridge remain required; observed checks and an optional exactly input-bound root certificate do not establish them. This branch handles known weights, and does not fit weights or validate the original refit bootstrap. See `?wm_fitted_inference` and `validation/check_scalar_psm_inference.R` for the full contract and saved-fixture validation.

`wm_bootstrap()` accepts a successful `scalar_psm` inference object and applies its usual Gaussian multipliers to the complete centered augmented rows. Alternatively supply `counts`, an n-by-B nonnegative integer matrix whose columns sum to full observed n; B is inferred when omitted, and frozen counts reject a seed. PATE and PATT retain the same raw point and total-n scaling. The analytic conditional variance is the centered-row square mean under the stated Gaussian or multinomial law, independent of empirical B-draw variation. Supplied columns do not verify that law. This contribution replication does not refit scores, smoothers or weights, rematch, or use a replicate treated-weight denominator. See `validation/check_scalar_psm_bootstrap.R` for deterministic saved-array and literal-count validation.

Corrected fits whose used matching maps all have dimension one use the same generic `wm_fitted_inference()` interface: PATE selects `covariance_scope = "full_x"` and omits transport specifications; PATT selects `"patt"`, supplies only control prediction derivatives, and declares `transport0 = list(mode = "zero", basis = "current_centering")`. Supply a complete joint `nuisance_influence` matrix and `mean_derivative0`/`mean_derivative1` in one parameter order, including score, prediction and empirical scaling parameters. The bounded design-fitted alternative retains correct full-X outcome predictions, known positive bounded `W = w_Z(X)`, bounded outcomes and design-measurable graph parameters and influences. Its direction-specific scalar chart, regular-root and empirical-row conditions are stated in `?wm_fitted_inference` and cannot be verified from saved arrays. Mixed scalar/higher dimensions, scalar `distinct_rarity`/`common_field` and estimated scalar transport are rejected. The raw `scalar_psm` path above retains its separate point estimator and finite-M drift contract.

The same corrected scalar calculation also has an exact outcome-fitted-root alternative. It requires a closed regular graph estimating root with the stated continuous-coordinate score-block domination/submersion, finite-piecewise quantitative density/mark charts, correct bounded full-X predictions and complete finite/conditional `2+delta` influence/residual moments. Full prediction/correction covariance may be singular. These are substantive sufficient conditions, not consequences of a fitted PG score or a converged model. The original scalar graph must use the exact root, an exactly graph-equivalent parameterization or a separately proved numerical transfer; `o_p(n^-1/2)` parameter error alone does not establish that transfer. `?wm_fitted_inference` gives both alternatives. Population/application assumptions remain unverified, and the existing saved scalar PS fixtures remain design-fitted arithmetic evidence.

A separate noncompact design-fitted correct-PS source branch allows unbounded supplied weights and correct raw full-X predictions under its scalar current-graph square/cross/maximum and prediction-gradient laws, likelihood-ratio/marked-local moment and cap-removal conditions, and complete regular influence. Correct PS alone does not establish those conditions or correct outcome predictions. The complete Gaussian sufficient route also covers design-measurable graphs and verified outcome-fitted graphs under exact determination by all design rows and the complete Gaussian noise projection, global second moments, integrated uniform current-graph laws and square-integrable prediction derivative/Hessian envelopes. These alternatives use the same generic corrected calculation and complete covariance, with PATT requiring only the correct control mean. Their numerical selection conditions remain; they do not identify corrected full-X PS matching with raw Abadie–Imbens PSM, certify arbitrary scalar geometry, or establish estimated-weight/dependent-design inference.


The same `wm_bootstrap()` contribution call accepts successful public `wm_fitted_inference()` results in these all-scalar full-X branches and the d>=2 zero-reciprocal scopes: PATE `distinct_rarity`, `full_x` or `common_field`, and PATT `patt`. It uses their complete centered `augmented_rows`, including the full joint nuisance slope and matching/nuisance covariance, and retains the exact source point. The source fit, dimensions, parameter axes and full covariance identities must agree; a row-only object or private WDSM result is insufficient. Gaussian multipliers and optional full-n counts share the same complete-row variance. Population assumptions and the applicable empirical variance/Lindeberg conditions remain required. This is full-slope contribution replication; it does not establish the original prediction-refit bootstrap or finite-sample coverage. `validation/check_general_fitted_bootstrap.R` checks stored fits and component arrays without fitting, new data or random draws, with an optional installed-package mode.

## Inference and nuisance inputs

PATE `covariance_scope = "regular_joint_d_gt2"` uses the same `wm_fitted_inference()` inputs for equal used dimensions d>2 under the bounded iid known-W/F1–F4 and finite regular baseline joint-sheet premises. It computes signed reciprocal products from the actual fitted graph and subtracts `2R/gamma^2` from the complete augmented-row variance, retaining full nuisance covariance. It reports the diagonal, signed R, raw corrected base and full contrast; a nonpositive base does not suppress a positive full contrast. Only final corrected variance governs interval availability, with no hidden floor. `wm_bootstrap(inference, method = "contribution")` explicitly generates marginal Gaussian roots from this corrected variance and rejects supplied counts; ordinary row/count multipliers omit the reciprocal covariance. The point, graph and known weights remain unchanged. Population assumptions, feasible prediction/influence/full-slope rates and positive limiting variance remain required; this does not establish original refitting/rematching validity or actual sampling-variance convergence. Existing zero-reciprocal outputs and count paths retain their contracts.

PATE `covariance_scope = "critical_planar"` uses the same `wm_fitted_inference()` interface for two actual matching coordinates in each arm, including distinct arm maps. Supply the complete joint `nuisance_influence`, prediction derivatives and graph-transport declarations, together with `critical_control`: matching-coordinate `n`-by-`2`-by-`p` tangent arrays, deterministic auxiliary rows, bandwidth, density/mass/projection/mark guards and numerical/work budgets. This bounded iid known-weight branch requires the documented own-score/weight centering and target identities, complete F1–F4 fitted-stack conditions, regular baseline joint sheets and complete plug-in consistency. The smooth-stack covariance-rate conditions justify the disclosed `n^(-1/3)` support threshold; rate-free influence consistency alone does not. These are caller premises, not conclusions of a successful fit.

The auxiliary calculation estimates the whole reciprocal function at nuisance indices, using full arm subdensities normalized by total auxiliary size, unweighted conditional donor-weight laws, guarded local rank-two geometry and ordered treated/control pairs. For each admitted fixed `M`, it retains both full donor-denominator factors; the geometric integral uses the exact finite `q = 2M-1` Hermite identity, and the donor functional uses controlled Laplace integration. Pair normalization is `N(N-1) h^2 (pi/3)` for the evaluation size `N`, and reciprocal subtraction is `2R(u)/gamma^2` in the original fit's analysis-weight units. There is no `M^-2` or mean-weight substitute. Propagated integration bounds exclude floating roundoff; statistical consistency requires a vanishing numerical-error sequence, not merely a fixed tolerance. Exceeded budgets produce explicit unavailability without changing the original point, weights or graph.

The complete nuisance axes, covariance and smooth-plus-transport slope remain. Raw covariance/eigenvalues, signed reciprocal values, raw Schur values and disclosed cone adjustments are retained; the operative Schur covariance is nonnegative. Scalar Wald variance, SE and interval fields in `wm_fitted_inference()` are `NA` for this generally non-Gaussian branch. `wm_bootstrap(inference, method = "contribution")` generates full nuisance Gaussian draws and a conditional Schur innovation. Its default interval is `basic` here; `basic` and `none` are supported, while explicitly requested Normal intervals, counts and refit callbacks are rejected. Every prescribed draw is retained, and any failed evaluation makes aggregate inference unavailable. Root sample variances use `B-1`; Rao–Blackwell averages and their MCSE are separately labeled finite-`B` Monte Carlo estimates. The exact conditional variance remains an unevaluated expectation and is reported as `NA`; `B=1` gives `NA` sample variance and MCSE. An optional direct raw-variance calculation is described below; it does not evaluate this operative cone expectation. Quantile validity still requires the complete-input and strict-CDF premises. This operation does not refit or rematch observations, estimate weights, establish nominal coverage or validate the original refit bootstrap.

The same API optionally accepts `critical_control$direct_variance = "raw_only"`, with `support` omitted. This rate-free raw calculation uses the complete empirical influence covariance and matching/nuisance cross block; it does not construct a support threshold, pseudoinverse or Hermite rule. Under the documented geometry, centering, full-stack and plug-in assumptions, it estimates the signed root-n variance `diagonal - 2*average_R/gamma^2 + 2*b'C + b'Sigma*b`. The common helper uses centered influence and matching rows, a disclosed finite-sample convention distinct from an uncentered moment formula. Negative values and covariance/precision/work diagnostics remain visible. Raw-only results do not authorize a Gaussian pivot or mixture bootstrap; scalar Wald fields remain `NA`. Omit `direct_variance` to preserve existing outputs, or use `"with_mixture"` with the existing support declaration to add both raw empirical and support-aligned raw quantities without changing the mixture calculation.

The direct Gaussian average retains the full four-shift covariance, including cross-arm blocks, and uses a fixed four-column covariance factor and a six-dimensional positive-definite matrix. Its normalized determinant-coefficient identity is finite and exact in exact arithmetic for every admitted fixed `M`, retaining both full donor denominators and the existing pair/weight normalization. Computation preserves the full nuisance dimension; it does not replace weights by their mean or add an `M^-2` factor. Numerical precision or work failures produce explicit unavailability. Donor-integration error bounds are propagated, floating roundoff is excluded, and statistical consistency still requires vanishing propagated error. The direct raw quantity differs from the operative nonnegative-cone variance: that exact conditional expectation remains `NA`, while generated-root sample variance and Rao–Blackwell averages/MCSE remain finite-`B` Monte Carlo summaries. See `?wm_fitted_inference` for controls and complete qualifications.

- `wm_graph_transport()` estimates an unnormalized arm-specific graph-transport vector by kernel/Laplace integration under its signed-support and smooth marked-density assumptions. Its numerical error bound concerns quadrature, not nuisance estimation or kernel bias; the returned vector is not itself a variance or interval.
- `wm_fitted_inference()` combines corrected self-normalized fits with supplied joint influences and complete sensitivities in the stated d>=2 branches and the all-scalar correct-full-X PATE `full_x` or PATT `patt` branch, under at least one stated scalar sampling-law alternative. Its explicitly selected `scalar_psm` branch supplies inference for the raw known-weight logistic PSM object described above. These branches retain complete covariance blocks and their distinct application-specific premises.
- `wm_reciprocal_inference()` uses complete centered rows and subtracts twice the signed reciprocal-pair covariance estimate. It allows distinct fixed arm maps for self-normalized and stabilized matching; PATT has no reciprocal term. It returns a separate result and preserves the point estimate. Nonpositive estimates are reported as unavailable by default; an optional explicit numerator-scale variance floor is recorded. `wm_reciprocal_bootstrap()` generates scalar Gaussian roots from this variance. Its sampling justification requires the separate CLT and feasible-point remainder, not just a Gaussian variance identity. These APIs exclude adjusted nuisance fits and multiple graph cells. Known maps/weights, boundedness, centering and nuisance-rate assumptions remain user-supplied premises.
- `wm_bootstrap()` selects the calculation with `method`. The default `"contribution"` applies Gaussian multipliers to fixed rows and, where required, unordered edges and independent-training components; supported zero-reciprocal/scalar fitted inference also accepts supplied full-n counts on its complete augmented rows. The Gaussian branches use analytic conditional variance for Normal intervals, independent of B. The `critical_planar` mixture instead uses the full nuisance/Schur calculation above and rejects Normal intervals and counts. With `method = "fixed_reuse"`, an ordinary self-normalized `wm_match` object of any supplied matching dimension, an `n`-by-`B` count matrix and an optional `refit` callback use the original fixed-reuse calculation. It preserves distinct arm maps, original weights and reuse, the random PATE/PATT replicate denominator, and variance divisor `B`. Normal and no-interval output are supported; basic intervals are unavailable for this method. Both methods keep the graph fixed.
- `wm_bootstrap_refit()` remains the direct fixed-reuse implementation called by `wm_bootstrap(..., method = "fixed_reuse")`. In the common `wm_bootstrap()` interface, B is inferred from supplied count columns when omitted; an explicit B must match. Counts must be nonnegative integers in original row order, with columns summing to full observed n and at least two columns for fixed-reuse replication. Do not supply a seed with frozen counts. A callback returns `mean0` and, for PATE, `mean1`; it performs the complete intended count refit or the proved compatible prediction-only operation. When fixed raw prediction equations are independent of inactive score coordinates, corresponding same-count weighted least-squares prediction roots retain the complete effect expansion under the complete-system and actual-row conditions. Complete polynomial predictions are invariant under invertible affine standardization. Full-covariate derivative locality gives zero slopes only under the applicable current-graph and sampling laws; other partial callbacks retain their actual influence/covariance. Supplied columns do not establish their multinomial law, and sampling validity requires the applicable refit expansion and sampling/replication variance agreement.
- `wm_prediction_adjust()` with supplied known weights and omitted weight derivatives includes qualified parametric prediction/score uncertainty and its covariance with matching contributions. `wm_training_adjust()` uses a separate contribution component for an independent training sample. Their theorem contracts are explicit in the documentation.
- `wm_gaussian_match()` fits a correct full-covariate linear outcome model with conditionally Gaussian errors, evaluates supplied score maps at the actual OLS coefficient, and includes prediction uncertainty. Weights must be fixed functions of treatment and those full covariates, including any outcome-informative weight marks. Its qualified contract permits scalar scores; it does not establish generic non-Gaussian scalar-score inference.
- Historical optional APIs `wm_logistic_weights()` and `wm_weight_adjust()`, and the nonzero `weight_derivative` route in `wm_prediction_adjust()`, remain for compatibility with the earlier development snapshot. Their estimated-weight calculations are outside the current supplied-weight WM framework and are not part of the paper's identification, variance or bootstrap results. Use supplied weights and omit weight derivatives in the current WM workflow.
- Spline fits require a declared fixed support, moment order, spline order and mesh exponent satisfying the documented strict rate window. Stabilized spline fits train outside fixed evaluation folds and match wholly inside each evaluation fold. Singular bases and insufficient donors produce explicit errors.
- `strata` restricts matches and nuisance fits. The applicable iid branch retains its own weight bounds or integrated moments, identification/overlap and within-stratum matching-geometry conditions. Selecting strata does not establish a fitted-score theorem's current-graph, root or moment premises, or provide inference for dependent cluster/stratum sampling.

Start with an ordinary generic matching object: `fit <- wm_match(Y, Z, W, scores0 = S0, scores1 = S1, M = M, estimand = "PATE", mean0 = q0, mean1 = q1, variance = FALSE)`. Supply S0/S1 as a propensity-score matrix, distinct-arm `cbind(PS, PG0)`/`cbind(PS, PG1)`, or full-X matrices, with the intended scaling; PATT omits S1 and q1. Then `wm_bootstrap(fit, method = "fixed_reuse", counts = counts, refit = refit_means)` delegates to the original calculation. The caller supplies frozen columns with positive multiplicity in both arms and a callback returning the complete intended mean predictions for each full-n multiplicity vector. Raw estimated PSM with `refit = NULL` does not add fitted-score drift or its covariance. A common interface does not make that unadjusted variance valid for estimated scores. Complete WDSM prediction-refit and complete-row contribution replication retain their respective inference contracts. `validation/check_wm_bootstrap_dispatch.R` verifies dispatch using saved objects and count columns, including an optional installed-package mode.

For a fixed number B of independent count draws, n times the original B-divisor variance has limit `V_rep * chi-square(B-1) / B`; it retains Monte Carlo variation. For deterministic `B_n -> infinity` with `B_n <= n^b` for some fixed finite b and conditionally independent full-n multinomial columns, the regular-root/actual-row refit conditions and a prediction derivative/Hessian envelope moment of order q>2 give empirical nonlinear variance consistency: `n * mean((draws - mean(draws))^2) -> V_rep`. Numerical callbacks need simultaneous nearby-root selection, success and compatible effect-error control over all prescribed columns. Positive agreement of the sampling and replication variances then justifies normal intervals. This empirical result does not assert nonlinear conditional-second-moment convergence. Failed prescribed columns stop this implementation and are never silently redrawn; arbitrary growing replication sequences outside this result retain separate moment and failure/completion requirements. See `?wm_bootstrap_refit`.

The software cannot establish causal identification, smoothness or an influence-function expansion from the observed data. Supplied learned coordinates require a supported fitted-inference branch and complete nuisance inputs; supplied weights are treated as known. See the function documentation for each supported contract and limitation. Unrestricted scalar fitted-score inference, dependent survey designs, estimated weights, growing dimension, variable donor counts and unrestricted discrete ties remain outside the supported branches described here.

## Explicit variance constants

```r
wm_geometry(M = 3, d = 1)  # exact one-dimensional formula
wm_geometry_overlap(M = 3, d = 2, draws = 20000, seed = 92) # complete beta vector
wm_geometry_alpha(M = 3, d = 2, draws = 20000, seed = 93)   # alpha only
```

For general dimensions, the boundary-rank integral returns component Monte Carlo errors, their covariance, and precision diagnostics. The original `wm_geometry()` angular integral remains available as a separate implementation, but can have large numerical error when M and d increase. `wm_geometry_alpha()` uses a separate bounded-integrand formula and does not supply the marked-overlap vector needed with variable donor weights. Zero-hit components are unresolved. Numerical estimates are not projected onto the Jensen lower bound. Contribution-based standard errors do not require evaluating these constants numerically.

These reductions concern point estimates and specified replication algorithms. They do not establish unrestricted distinct-score inference: even with weights one and a correct propensity, residual centering on each arm's own score does not imply centering on the union of both scores. Nonzero heterogeneity/residual and reciprocal covariance can remain. For fixed maps and bounded marks, the reciprocal limit has an explicit marked expression for a finite smooth joint-score-stratum class with full-rank projections, regular marginal donor geometry and almost-everywhere continuous conditional donor-weight laws given each arm's own score. For equal arm dimension d, distinct d-dimensional components must intersect only on d-dimensional Hausdorff-null sets; only pairs within the same d-dimensional component can contribute, while cross-component pairs and higher-dimensional strata have zero limit. Unequal arm dimensions have zero reciprocal limit under the corresponding regular-stratum conditions. This result does not cover arbitrary singular joint laws, and the geometry APIs do not automatically identify strata or evaluate that general reciprocal constant. Qualified known-weight fitted-map branches retain the complete joint score/prediction/scaling covariance and require their own graph-transfer conditions.
